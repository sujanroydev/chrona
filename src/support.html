Learn how Chrona works and what to do when something goes wrong.

How Chrona works

Chrona records active computer usage and the foreground application while you are using Windows. Usage is grouped into days and sessions so you can review your activity later.

  1. Keep Chrona running while you use your computer.
  2. Open Usage to review daily activity.
  3. Select an application to inspect its 30-day history.

Common issues

Usage is not increasingCheck the home screen status. If tracking is paused, click “Resume tracking”. Also make sure Chrona is still running.
An application is missingChrona identifies the foreground Windows process. Some system processes or short-lived applications may not appear as expected.
The time looks incorrectChrona depends on Windows activity and idle information. Restarting Chrona can help after a system sleep, restart, or unusual process state.
Data disappearedAvoid deleting or editing Chrona's local data files manually. If the problem continues, report the issue with the affected date and what happened.

Issues & feedback

If Chrona behaves incorrectly, include the Chrona version, Windows version, affected date, and a short description of what you expected versus what happened. Screenshots are useful when reporting display problems.

Report an issue Open the Chrona issue tracker on GitHub. Chrona on GitHub View the project, releases, and source code.

Privacy

Chrona is designed as a local Windows activity tracker. See the privacy policy included with your Chrona release for details about what data is collected, stored, and used.

About Chrona

Chrona is a lightweight laptop activity tracker for Windows. It focuses on simple screen-time and application-usage history without unnecessary complexity.

Need more help? Include as much useful diagnostic information as possible when reporting an issue.
